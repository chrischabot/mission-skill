# Rejected lessons

Candidate rules that `drive:auditor` rejected, recorded so a false lesson is not proposed twice.
Dedupe searches this file. A candidate that matches a record here goes no further unless it brings
new evidence that answers the recorded reason; in that case it is proposed again and the record is
left in place with a line pointing to the new verdict. Entries are appended and never removed.

Entry shape:

```markdown
### <the candidate rule's heading, verbatim>
- Rejected: <date> · Failing question: <the first of the nine auditor questions that failed>
- Reason: <one or two sentences from the auditor's verdict>
- Would change the verdict: <the evidence that would answer the reason>
- Source: <failure event type and date; no project names>
```
